정현욱(Designer)님의 작업물과 프로젝트를 효과적으로 보여주기 위해 제작한 포트폴리오 웹사이트입니다.

## 🧩 Overview

- 반응형 웹 구현 (Desktop / Tablet / Mobile)
- 개인 포트폴리오 웹사이트 제작 프로젝트
- 프로젝트 중심의 정보 구조 및 UI 구성
- 모달 기반 상세 콘텐츠 인터랙션 구현
- 다크모드 기능 추가 및 테마 전환 UI 구성
- 반응형 레이아웃을 고려한 화면 설계

## 🛠 Tech Stack

- HTML / CSS / JavaScript
- jQuery

---

## 👨‍💻 Key Points

- 프로젝트 목록과 상세 내용을 자연스럽게 연결할 수 있도록 UI 흐름 구성
- 모달 인터페이스를 활용해 작업물 정보와 세부 콘텐츠를 직관적으로 전달
- 라이트/다크모드 전환 기능을 적용해 사용자 환경에 따라 다른 화면 경험 제공
- 사용자 시선 흐름을 고려해 메인 화면과 상세 화면의 정보 우선순위를 정리
- 모바일 환경에서도 레이아웃과 인터랙션이 자연스럽게 유지되도록 반응형 대응

## 💡 What I Learned

- 포트폴리오 사이트는 단순히 작업물을 나열하는 것이 아니라, 사용자가 프로젝트를 이해하고 흐름을 따라갈 수 있도록 구조를 설계하는 것이 중요하다는 점을 배웠습니다.
- 모달 UI를 활용한 상세 콘텐츠 구성에서는 시각적인 완성도뿐 아니라, 닫기 동작이나 화면 전환 흐름처럼 사용자 경험에 직접 영향을 주는 요소를 꼼꼼하게 다듬는 것이 중요하다는 점을 경험했습니다.
- 다크모드 기능을 추가하면서 단순한 색상 변경이 아니라, 각 테마에서 가독성과 분위기가 자연스럽게 유지되도록 전체 UI 톤을 함께 조정하는 과정이 중요하다는 점을 느꼈습니다.
- 반응형 환경에서는 레이아웃뿐 아니라 상세 보기, 모달 인터랙션, 테마 전환까지 함께 고려해야 완성도 높은 포트폴리오 사이트가 된다는 점을 배웠습니다.
